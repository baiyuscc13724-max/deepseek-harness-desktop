# Microsoft Store 商品页（简体中文）

## 产品名称

Harness Desktop

## 简短说明

在 Windows 上本地运行 DeepSeek Harness 的独立社区桌面客户端。

## 说明

Harness Desktop 将开源 DeepSeek Harness 工作台封装为 Windows 桌面应用，并自动启动本机运行时。你可以管理项目与会话、配置自己的 AI 服务商和模型、使用工具与子代理，以及按需安装社区插件。

本应用包含生成式 AI 功能。你的提示词、附件、所选文件片段和上下文可能发送给你自行配置的第三方 AI 服务商；输出可能不准确或不适当，重要用途前请人工核验。

主要功能：

- 本机启动并承载 Harness 工作台
- 项目和会话管理
- 主模型与子代理模型独立路由
- 桌面托盘和与启动状态同步的启动动画
- 社区插件入口与本地配置
- Microsoft Store 管理桌面应用更新

Harness Desktop 是独立社区项目，并非 DeepSeek 官方产品，也不代表 DeepSeek 或 Microsoft 的认可。
