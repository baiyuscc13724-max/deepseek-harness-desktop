# Microsoft Store listing (English - United States)

## Product name

Harness Desktop

## Short description

An independent community desktop client that runs DeepSeek Harness locally on Windows.

## Description

Harness Desktop packages the open-source DeepSeek Harness workbench as a Windows desktop application and starts its local runtime automatically. Manage projects and sessions, configure your own AI providers and models, use tools and subagents, and optionally install community plugins.

This application includes generative AI functionality. Prompts, attachments, selected file excerpts, and context may be sent to third-party AI providers configured by the user. Output can be inaccurate or inappropriate and should be reviewed before important use.

Highlights:

- Local Harness workbench startup and hosting
- Project and session management
- Independent model routing for the main agent and subagents
- Desktop tray and readiness-synchronized startup animation
- Community plugin access and local configuration
- Desktop application updates managed by Microsoft Store

Harness Desktop is an independent community project. It is not an official DeepSeek product and does not imply endorsement by DeepSeek or Microsoft.
