# 品牌与图标说明

安装包、便携版、程序文件、快捷方式和 Windows 卸载列表统一使用 `build/icon.png` 中的官方 DeepSeek 蓝色鲸鱼图标。启动状态使用同源的 `renderer/assets/deepseek-icon.svg`。

图标为 512×512 透明 PNG，来源于 DeepSeek 官方 GitHub Logo 资产。发布自检锁定其 SHA-256；未经明确品牌决策替换图标会阻断验证。

本项目必须在 README 与发布说明中明确：这是社区维护的非官方开源桌面壳，不代表 DeepSeek 官方背书、合作或发布。

DeepSeek Harness 的 MIT License 与 DeepSeek 商标/品牌权不是同一概念。发行者仍应确认并遵守最新品牌规则。
