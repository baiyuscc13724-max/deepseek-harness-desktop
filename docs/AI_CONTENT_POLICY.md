# Generative AI Content Policy / 生成式 AI 内容规则

Harness Desktop is a local client that lets users connect providers and generative AI models of their choice. It does not guarantee the accuracy, safety, legality, or suitability of model output.

Harness Desktop 是允许用户自行连接服务商及生成式 AI 模型的本地客户端，不保证模型输出的准确性、安全性、合法性或适用性。

Users must not intentionally use the application to generate, store, or distribute content that is unlawful, facilitates serious harm, sexually exploits minors, violates privacy or intellectual-property rights, or violates the applicable AI provider's terms.

用户不得故意使用本应用生成、保存或传播违法内容、促成严重伤害的内容、涉及未成年人性剥削的内容、侵犯隐私或知识产权的内容，或违反相应 AI 服务商条款的内容。

AI output should be reviewed by a person before it is used for medical, legal, financial, safety-critical, publication, or production decisions. Model output must not be represented as verified fact merely because it was generated by the application.

医疗、法律、财务、安全关键、出版或生产用途的 AI 输出必须先由人工核验。不得仅因内容由本应用生成就将其表述为已核实事实。

Report potentially unlawful or harmful output at:

举报可能违法或有害的输出：

https://github.com/baiyuscc13724-max/deepseek-harness-desktop/issues/new?template=ai-content-report.yml

Reports should not include API keys, passwords, private source code, personal identifiers, or other secrets. Include only the minimum excerpt necessary to understand the issue.

举报中不得包含 API 密钥、密码、私有源代码、个人身份信息或其他秘密，只提供判断问题所需的最少内容。
