# Plugin Content Policy / 插件内容规则

Harness Desktop can expose a community plugin marketplace. Plugins are independent third-party software and are not endorsed, reviewed, or warranted by Harness Desktop, DeepSeek, or Microsoft merely because they appear in the marketplace.

Harness Desktop 可显示社区插件市场。插件属于独立第三方软件；仅因插件出现在市场中，不代表 Harness Desktop、DeepSeek 或 Microsoft 对其作出认可、审核或担保。

Before installing a plugin, users should review its source, requested access, network destinations, license, maintainer, and update history. A plugin can run local code with the user's permissions and may read files or contact external services.

安装插件前，用户应检查其源代码、所需访问权限、网络目标、许可证、维护者和更新记录。插件可能以用户权限执行本地代码、读取文件或访问外部服务。

Marketplace entries and plugins must not:

- contain malware, credential theft, deceptive behavior, or undisclosed tracking;
- enable illegal activity or serious harm;
- distribute content without the necessary license;
- falsely claim affiliation with Harness Desktop, DeepSeek, Microsoft, or another party;
- transform the application into functionality that violates Microsoft Store policy.

插件市场条目及插件不得包含恶意软件、凭据窃取、欺骗行为或未披露的追踪，不得促成违法活动或严重伤害，不得无授权分发内容，不得虚假声称与任何品牌有关联，也不得将应用变成违反 Microsoft Store 政策的用途。

Report a plugin by opening an issue and including its name, repository URL, version or commit, and a concise reason. Do not include secrets:

https://github.com/baiyuscc13724-max/deepseek-harness-desktop/issues/new

Maintainers may remove or block a marketplace listing after reviewing credible reports. Removing a listing does not automatically remove copies already installed on user devices.

维护者可在核实可信举报后移除或屏蔽插件条目。移除条目不会自动删除用户设备上已经安装的副本。
