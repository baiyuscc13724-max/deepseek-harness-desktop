# Harness Desktop v1.0.50 安全、权限与隐私审查

审查范围：Mobile Orbit 工作台、Android 原生输入与附件、iOS/iPadOS 共享移动资源和前台恢复、手机模型额度/插件投影、统一更新中心、完整桌面 Computer Use、多显示器坐标、Agent Teams/会话状态、浏览器启动、右侧文件预览、工具结果图片、打包模型目录、安全 literal edit 恢复、Codex 过载重试，以及完整 `1.0.50` 发布身份。

## 结论

v1.0.50 **有一项明确、需要用户重新理解的权限扩大**：在用户通过可信 Harness Desktop 授权卡开启 Computer Use 后，桌面控制从目标窗口模型改为完整 Windows 虚拟桌面模型。它可以截取全部显示器，并向当前获得焦点的桌面应用发送全局点击、滚动和文本；不再提供窗口选择器、逐动作确认或按内容识别的敏感窗口/敏感输入过滤。永久授权会在应用启动时自动恢复共享控制会话。

这项扩大不改变浏览器结构化控制的密码、账户、验证码、支付、银行及交易硬边界，也不增加 Shell/脚本能力。用户可随时按 `Esc`、点击停止，或在“设置 → 插件 → Computer Use”撤销永久授权。

除此以外，本版移动、文件、重试和发布改动均维持或收紧既有边界：手机投影只读且有界，Android 使用系统选择器与临时授权，文件预览仍受来源/路径/MIME/大小约束，认证与额度错误不进入过载重试，历史发布不被覆盖。

## 1. Computer Use 完整桌面权限

### 授权与范围

- 只有可信 Host 推送的“本次授权 / 永久授权”卡能授予控制；插件卡本身只能请求授权、读取状态、停止或撤销，不能自行授权。
- 本次授权在当前应用运行期有效；永久授权持久化，并在 Harness Desktop 启动时恢复共享控制会话。
- 锁屏、睡眠、系统会话切换会暂停采集与输入；解锁/恢复时重新建立完整桌面捕获。
- 截图覆盖所有显示器组成的一个虚拟桌面。工具只暴露最新截图的 `width`、`height` 与合法输入边界；模型不得按显示器或原始源分辨率再次缩放。
- 点击与滚动使用截图像素坐标，由宿主映射到全局桌面；文本发送给当前焦点控件。
- 透明置顶指示覆盖每块显示器、不拦截鼠标，也不进入 Computer Use 截图。

### 已移除的旧边界

授权后不再存在：

- 单窗口目标选择和窗口绑定；
- 逐次点击/滚动/输入确认；
- 基于内容的敏感窗口、敏感操作或敏感文本过滤；
- 应用级持久策略对桌面输入的限制；
- 对 UAC、系统、提升权限或敏感输入窗口的 Harness 自有拦截。

Windows 受保护桌面仍可能由操作系统拒绝输入，但这不是 Harness 安全承诺。用户应把 Computer Use 授权视为对当前完整桌面会话的高权限授权。

### 仍保留的边界

- Computer Use 工具不提供 Shell 或任意脚本。
- `Esc` 或 Stop 立即结束共享控制目标；撤销永久授权同时阻止下次自动恢复。
- 网页任务在 CDP/DOM 数据通道可用时必须使用 `browser_control`，不能改用桌面截图坐标。
- `browser_control` 继续禁止输入密码、账户、验证码、支付和银行内容，也不执行登录、付款、取款、转账流程。

## 2. Mobile Orbit 权威状态与只读投影

- 四域导航只映射官方对话、Agent Teams、定时任务和设置，不创建第二份业务状态。
- 团队、任务、项目和来源会话使用官方稳定 ID；同名项目不合并，不按展示名称推断对象。
- TodoDock、QueueDock 和任务动作继续由官方组件执行；移动适配层只改变布局与触控尺寸。
- 未读清除要求同一会话的最新权威历史成功加载；过期、失败、取消、子代理或不匹配响应不能生成回执。
- 模型路由、Provider 额度和插件清单来自已配对电脑的只读接口。接口仅允许 GET、返回 `Cache-Control: no-store`，限制 Provider/插件/计量条目和文本长度。
- DTO 去除凭据、原始 Provider 响应、配置值、本机路径、私密来源字段和不受信错误文本；读取失败使用有界通用错误，不回显底层秘密。
- 手机端不提供受保护设置或凭据写入口。

## 3. Android 原生输入、附件和截图隐私

- 相册使用系统 Photo Picker；文件使用 `ACTION_OPEN_DOCUMENT`。只授予本次临时读取权限，不调用持久 URI 授权。
- Manifest 不申请 `READ_MEDIA_IMAGES`、`READ_MEDIA_VIDEO`、`READ_EXTERNAL_STORAGE` 或 `WRITE_EXTERNAL_STORAGE`。
- 拍摄使用 `${applicationId}.mobile-inputs` FileProvider 和仅位于应用 cache 的 `mobile-input/` 路径；输出上限 12 MiB，并在成功、取消、异常和 Activity 清理路径删除临时文件。
- 语音输入委托系统 Recognizer，不固定覆盖系统语言，也不申请 `RECORD_AUDIO`。
- JS bridge 只接受 `capture`、`speech` 两个固定动作及两个固定回调，在 UI 线程执行，返回值使用 JSON 安全编码。
- 附件继续进入官方 paste/drop 预览，不绕过官方发送流程。
- 屏幕捕获回调只发出“发生截图”的事件并显示用户提示，不读取、保存或上传截图像素。
- WebView `onResume` 不 reload，避免草稿和滚动状态丢失。

## 4. iOS/iPadOS

- iOS 与 Android 共用审查后的移动 CSS/运行时资源，平台能力通过显式 gate 区分；Android 原生能力不会在 iOS 假装可用。
- Scene 前台恢复只在 active transition 调用，配对恢复幂等并感知网络状态。
- 没有 Apple Developer 会员时不产生或发布未签名 IPA；只运行 iPhone/iPad 模拟器门禁，并保留 Safari/添加到主屏幕方案。

## 5. 网络与配对

- 配对 cookie、10 分钟一次性二维码、设备撤销、loopback-only 桌面控制端点和版本化固定动作不变。
- 移动状态投影不包含 mesh/WSS 密钥、relay secret 或桌面控制 bearer；桌面 bearer 每次服务生成轮换并在停止时删除。
- Android LAN socket 优先选择非 VPN 物理网络，失败才回退系统路由；不会创建或替换用户 VPN。
- 原生 P2P 与既有端到端加密 WSS/SOCKS 后备并存；中继继续只能看到有界信令和密文盲转发载荷。

## 6. 更新中心与 Preview

- 稳定版、组件和 PR Preview 共用展示层，但继续使用各自签名、摘要、来源提交、显式应用、健康检查和回滚边界。
- 已安装 Preview 以精确 PR/head 持久去重；只抑制完全相同的 head，新 head 仍可更新。
- Preview 激活和失败恢复保存稳定基线；未知指针或不健康激活 fail closed，不猜测回滚对象。
- 打开更新中心不会自动安装；用户必须明确点击更新和安装/应用。

## 7. 文件预览与工具结果图片

- 工作区相对路径必须解析到当前工作区内；网络/远程返回的路径不能借遍历逃逸。
- 工作区外绝对路径只在用户明确点击该路径时只读放行，不扩展为目录权限。
- 图片、音频、视频、PDF、HTML 和文本执行扩展名/MIME、来源与大小限制；不受支持类型交给系统显式打开。
- 工具结果图片只信任桌面附件存储物化并登记的本地资产；任意 `file:` URL、恶意远程图片和超大 data URL 不直接渲染。
- 右侧 HTML 预览继续处于隔离内容面，不把页面文字当作系统指令。

## 8. 浏览器、编辑恢复与过载重试

- 浏览器首次导航只把严格空 URL 与 `about:blank` 当作安全启动页；内部错误页或其他 scheme 不能借启动分支建立来源。
- 浏览器普通动作可后台运行，但密码、账户、验证码、支付和交易限制不因共享授权而放宽。
- `edit` 找不到 literal anchor 时先要求重新读取，只允许一次短、唯一、有界候选；多个候选或范围扩大即拒绝。
- Codex overload 仅窄匹配官方临时过载错误，最多五次可取消指数退避；流式中途失败也受相同上限。
- `AUTH`、CreditsError、余额不足和其他 Provider 错误明确排除；无测试随机源时生产退避确定性。

## 9. Agent Teams、会话和本地持久化

- Agent Teams 分离访问权错误、成员失败、受控停止和无内容完成；失败成员不能继续接收未完成任务。
- 团队最终结果仍只接受匹配成员运行的最终文本并有长度上限；工具事件、内部协调载荷和非文本块不投影。
- 会话置顶、未读和起始时间保存于桌面受控状态，只允许当前本机 Harness 界面访问；移动已读使用精确历史回执同步。

- 根 package/lock、14 个随包插件、Android、iOS/iPadOS、桌面移动版本、移动更新示例和工作流默认值绑定 `1.0.50`。
- Android `versionCode=1005000`；iOS marketing version `1.0.50`、build `10050`。
- 纳入 PR #27、#28、#29、#30、#34、#35、#37、#39、#40、#41、#42；PR #33 累计 head 作为 ancestry/inclusion 证明。
- 正式发布只能由仓库 resumable publisher 从干净已提交源码执行，绑定精确 main SHA，再创建不可变 `v1.0.50`。
- 桌面、Android 与组件只在 GitHub Actions/受保护云端构建和签名；本机不生成或上传正式二进制，CNB 只从 GitHub 云到云镜像。

## 11. 验证门禁

发布前要求：

- 全量 `npm run verify`；
- 移动运行时、四域导航、返回协议、IME/截图、原生四动作、Agent Team/任务槽、额度/插件 DTO 和移动历史回执测试；
- Android Gradle 单元测试、lint/assemble 验证及云端签名身份校验；
- macOS/iPhone/iPad 模拟器与桌面打包云端门禁；
- release audit、静态安全检查、依赖 HTTPS/强摘要、Actions SHA 固定检查；
- GitHub/CNB 精确 18 资产、SHA-256、APK 包名/签名、组件签名和 stable-last 验证。

## 12. 用户建议

- 只在理解完整桌面权限后授予 Computer Use；不需要跨重启控制时选择“本次授权”。
- 使用永久授权后，任务结束请按 `Esc` 或在“设置 → 插件 → Computer Use”停止；不再需要时撤销永久授权。
- 不要在显示密码、验证码、支付、银行或其他敏感内容时让完整桌面 Computer Use 保持开启。
- Android 只安装 v1.0.50 Release 的正式 APK，并核对 `.sha256`；签名冲突时先理解卸载会清除配对/数据，再决定是否处理。
- 从 GitHub 或 CNB 下载后核对 `SHA256SUMS.txt`；两云同名文件摘要不一致时不要运行。
